# Mini Quiz

## Opis

Prosta aplikacja quizowa na Androida.  
Użytkownik odpowiada na pytania i na końcu pokazuje się wynik.

## Funkcje

* 5 pytań w quizie
* pytania losują się z puli 10 pytań
* 3 odpowiedzi do wyboru
* zliczanie punktów
* przycisk start i reset

## Jak uruchomić

1. Sklonować repo:
   git clone https://github.com/twoj_login/mini-quiz.git

2. Otworzyć projekt w Android Studio

3. Uruchomić na emulatorze albo telefonie
